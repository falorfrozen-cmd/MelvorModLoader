## Cheat Menu
{: .d-inline-block }

F8
{: .label .label-gold }

60+ settings and tools in one window: XP and game speed multipliers, extra bank slots, skill bonuses, god mode,
a loot filter, a list of materials no recipe should ask for (Coal, for example), per-skill XP and speed, giving
items and currency, setting levels. Every setting is per character and applies the moment you change it.

![The Cheat Menu window](../assets/img/mod-cheat-menu.png)

[Download on Nexus Mods](https://www.nexusmods.com/melvoridle2/mods/3){: .btn .btn-primary }

## Bulk Sell
{: .d-inline-block }

F7
{: .label .label-gold }

Buttons in the bank: **Bulk sell** (a window to pick many items and sell them in one go), **Sell junk** (your
own junk list, one click), **Bury all** and **Open all**. Locked stacks are never sold. Everything asks for a
second click first.

![The bank with the new buttons](../assets/img/mod-bulk-sell.png)

[Download on Nexus Mods](https://www.nexusmods.com/melvoridle2/mods/4){: .btn .btn-primary }

## Action Queue
{: .d-inline-block }

F6
{: .label .label-gold }

Line up actions, each with a goal ("until I own 1,000 logs", "until Fishing level 30", "for 45 minutes",
"until only 5 food are left"), and the game works through them. **Plan an item** works out every step to make
100 of something. Save queues under a name, switch between them, share them as a short code. Not a cheat: it
only presses the buttons you would press.

![Three queue steps running side by side](../assets/img/mod-action-queue.png)

[Download on Nexus Mods](https://www.nexusmods.com/melvoridle2/mods/5){: .btn .btn-primary }

## Multitask
{: .d-inline-block }

F5
{: .label .label-gold }

Switch a slot on and play as usual: when you start a new action, the one you were doing keeps running next to
it. One slot = your last two actions, both slots = your last three. Works with Action Queue: the queue then runs
several of its steps at once. A cheat.

![The Multitask window](../assets/img/mod-multitask.png)

[Download on Nexus Mods](https://www.nexusmods.com/melvoridle2/mods/8){: .btn .btn-primary }

## Save Backup

Every time the game starts, all your save files are copied to a dated folder:
`%APPDATA%\Games By Malcs\Melvor Idle 2\mod_save_backups`. The newest 20 are kept, and nothing is copied when
nothing changed. Nothing to press.

[Download on Nexus Mods](https://www.nexusmods.com/melvoridle2/mods/6){: .btn .btn-primary }

## Debug Menu
{: .d-inline-block }

F9
{: .label .label-gold }

Opens the debug menu the developers left in the game (give items, set levels, add offline time...). It is an
optional file on the [loader's page](https://www.nexusmods.com/melvoridle2/mods/2).
