Save Backup

KATEGORI ONERISI (Category):
Utilities

KISA ACIKLAMA (Summary / Brief overview, 186 karakter):
Copies all Melvor Idle 2 save files to a dated backup folder every time the game starts. Keeps the newest 20, skips the copy when nothing changed. Nothing to press, nothing to configure.

[size=5][b]Start here[/b][/size]
This is Save Backup [b]0.1.1[/b], tested on game version [b]0.11.6-alpha.1[/b] with Melvor Mod Loader 0.1.3. Install it and forget about it.

[size=5][b]What it does[/b][/size]
[list]
[*]On every game start it copies all save files to
[code]%APPDATA%\Games By Malcs\Melvor Idle 2\mod_save_backups\<date_time>\[/code]
[*]It keeps the newest [b]20[/b] backups and removes older ones.
[*]It makes no new backup when nothing has changed since the last one.
[*]The game is in alpha and mods change your game. This is the cheap insurance.
[/list]

[size=5][b]Restoring a save[/b][/size]
[list=1]
[*]Close the game.
[*]Open the backup folder above and pick a date.
[*]Copy the [b].sav[/b] file over the file with the same name in the game's [b]saves[/b] folder.
[/list]

[size=5][b]Install[/b][/size]
[list=1]
[*]Install [b]Melvor Mod Loader[/b] first (see Requirements).
[*]Open the game folder: Steam > right-click Melvor Idle 2 > Manage > Browse local files.
[*]Extract [b]SaveBackup-0.1.1.zip[/b] there. The mod ends up in [b]mods\SaveBackup[/b].
[*]Start the game from Steam as usual.
[/list]
No installer, no .exe, no script. Nothing is written outside the game folder.

[size=5][b]Uninstall[/b][/size]
Delete the folder [b]mods\SaveBackup[/b]. Your existing backups stay where they are.
