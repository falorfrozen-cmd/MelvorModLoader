Mod loader

KISA ACIKLAMA (Summary / Brief overview, 218 karakter):
The mod loader for Melvor Idle 2. Extract one zip into the game folder and the game loads C# mods from a "mods" folder. No game files are changed, no .exe, removed by deleting two items. Includes a kit for mod authors.

None.

DEGISIKLIK LISTESI (Changelogs sekmesi):
0.3.0
- New: the loader tells you on the screen when a mod did not start or was switched off after an error (nearly always a game update), not only in the log
- New: a mod that is still in the mods folder and did not start is not treated as removed: its items in your save are left alone (not turned into normal items), and a copy of the save is kept in mods\rescue-kept
- New: items come back when you remove a mod. A mod that keeps its own items in your save (One Style's rare items and the rings in its extra ring slots) leaves a list in the save; open that character without the mod and the loader puts the normal items in your bank, once. With a full bank nothing is lost: what does not fit waits (mods\rescue-pending.json) and goes in as soon as you free a bank slot
- A mod that also works with another mod (when that one is installed) now loads without it too
- A mod that holds the game up for more than a quarter second in a frame is named in MelvorModLoader.log ("Slow frame"), so a freeze can be traced

0.2.0
- New: the Mods menu. A "Mods" button in the game's top bar (or F1) lists every mod window; click to open one
- Every mod key can be changed or switched off there (press the new key, Ctrl/Shift/Alt allowed); two windows on one key are shown in orange; kept in mods\hotkeys.json
- Letter keys do nothing while you type in a text box
- For mod authors: ctx.AddWindow(title, toggle, key) puts your window in the menu
- Debug Menu 1.0.3: its key can be changed in the Mods menu

0.1.3
- Mods are held back while the game computes offline progress, so nothing can interfere with it
- New: GameAccess.IsComputingOffline for mod authors
- Modder's Kit: guide and example mod

0.1.2
- All log messages in English

0.1.1
- First public version

[center][size=6][b]MELVOR MOD LOADER[/b][/size]
[size=4][i]Mods for Melvor Idle 2. One zip, no game files touched.[/i][/size]
Extract it into the game folder and the game loads every mod you put in its [b]mods[/b] folder.
For players it is a one-time install. For mod authors it is a small, typed C# API with full access to the game.[/center]

[size=5][b]Start here[/b][/size]
This is Melvor Mod Loader [b]0.3.0[/b] for Windows / Steam, tested on game version [b]0.11.7[/b] (the update of 25 November 2026). Melvor Idle 2 is in alpha: a game update can break the loader or a mod until they are updated. If the game ever fails to start, delete [b]override.cfg[/b] and it runs without mods again.

[size=5][b]What it does[/b][/size]
[list]
[*][b]Loads mods.[/b] Every mod is a folder under [b]mods[/b]. Add a folder to install, delete it to uninstall.
[*][b]Leaves the game alone.[/b] It uses a standard feature of the Godot engine (an [b]override.cfg[/b] file) to start first, then starts the game's own untouched code. Not a single game file is modified or replaced.
[*][b]Keeps mods apart.[/b] A mod that fails is reported in the log and skipped. The game and the other mods keep running.
[*][b]Stays out of the way.[/b] A green line in the top-left corner shows the loader version and the number of mods for 15 seconds at start. That is all you see of it.
[*][b]Protects offline progress.[/b] While the game computes offline progress, mods are held back so nothing interferes with it.
[*][b]Gives items back (new in 0.3.0).[/b] Remove a mod that keeps its own items in your save, such as One Style's rare items, and the next time you open that character the loader puts their normal versions in your bank. Nothing is lost, nothing is doubled. Is your bank full? The items that do not fit wait (an orange note under the game's top bar and MelvorModLoader.log say how many) and go in as soon as you free a bank slot.
[*][b]One menu for all mods (new in 0.2.0).[/b] A [b]Mods[/b] button in the top bar (or F1) lists every mod window. Click a name to open it, click its key to give it another one, or press Off to free the key. Two mods on one key? Both rows turn orange.
[/list]

[size=5][b]Mods that use it[/b][/size]
[list]
[*][url=https://www.nexusmods.com/melvoridle2/mods/3][b]Cheat Menu[/b][/url] (F8): 60+ settings and tools in one window: XP, speed, bank, skills, combat, loot filter.
[*][url=https://www.nexusmods.com/melvoridle2/mods/4][b]Bulk Sell[/b][/url] (F7): bulk sell window, one-click "Sell junk", "Bury all" and "Open all" buttons in the bank.
[*][url=https://www.nexusmods.com/melvoridle2/mods/5][b]Action Queue[/b][/url] (F6): chain actions, "cut 1,000 logs, burn them, then go fishing".
[*][url=https://www.nexusmods.com/melvoridle2/mods/6][b]Save Backup[/b][/url]: dated copies of your saves on every start.
[*][url=https://www.nexusmods.com/melvoridle2/mods/8][b]Multitask[/b][/url] (F5): keep up to 15 extra actions running beside your main one. A cheat.
[*][b]Debug Menu[/b] (F9, optional file on this page): opens the developers' own hidden debug menu.
[/list]
Each has its own page: click a name above.

[size=5][b]Install[/b][/size]
[list=1]
[*]Open the game folder: Steam > right-click Melvor Idle 2 > Manage > Browse local files.
[*]Extract [b]MelvorModLoader-0.3.0.zip[/b] there. [b]override.cfg[/b] must end up next to [b]Melvor2.exe[/b].
[*]Start the game from Steam as usual.
[/list]
No installer, no .exe, no script. Nothing is written outside the game folder.
A green "Melvor Mod Loader" line in the top-left corner tells you it works.

[size=5][b]Uninstall[/b][/size]
Delete [b]override.cfg[/b] and the folder [b]data_MelvorModLoader_windows_x86_64[/b]. The game starts exactly as before.

[size=5][b]For mod authors[/b][/size]
Mods are C# class libraries. Your code runs inside the game with direct, type-checked access to the game's own classes: the bank, skills, combat, every screen. No scripting layer in between.
[code]public class MyMod : IMod
{
    public void OnLoad(ModContext ctx)
    {
        ctx.Log("hello");
        ctx.Frame += () => { /* runs every frame */ };
    }
}[/code]
[list]
[*]Start with the [url=https://falorfrozen-cmd.github.io/MelvorModLoader/modding/first-mod]modding wiki[/url]: your first mod in ten minutes, a map of the game's classes and tested copy-paste recipes.
[*]Download the [b]Modder's Kit[/b] from the Files tab: a guide ([b]MODDING.md[/b]) and a complete example mod that builds straight into your game folder with one command.
[*]The whole API is one interface, one context object (log, your folder, the scene tree, a per-frame event, a place in the Mods menu with a key the player can change) and a few shortcuts into the running game.
[*]Several mods run side by side. Without a loader only one mod could hook the game at a time.
[*]Limits, honestly: C# only; no built-in tool for rewriting the inside of existing game functions; no in-game installer (you add and remove folders).
[/list]

[size=5][b]Safe to download[/b][/size]
[list]
[*]No .exe, no .bat, no installer in the package.
[*]The loader itself is one small file, [b]MelvorModLoader.dll[/b]. Open source: read or build it yourself on [url=https://github.com/falorfrozen-cmd/MelvorModLoader]GitHub[/url].
[*]The rest of the folder is Microsoft's own .NET 10 runtime (MIT license, digitally signed by Microsoft), which the engine needs to start the loader. That is why the download is about 34 MB.
[*]None of the game's own files are changed or included.
[/list]

[size=5][b]Good to know[/b][/size]
[list]
[*]Windows / Steam only for now.
[*]Mods change your game. Keep backups of your saves (the Save Backup mod does it for you).
[*]This is an unofficial, fan-made project and is not affiliated with the developers of Melvor Idle 2.
[/list]
